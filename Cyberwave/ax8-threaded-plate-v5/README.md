# FLIR AX8 threaded plate v5.0 (printable)

Mounting plate for the FLIR AX8 with a modeled 1/4-20 UNC thread, sealed air sacs, logo engraving.
Envelope 50 x 96 x 17.35 mm, camera-contact face at Z=0, prints as-is (-z), 0 floating regions,
no supports. Slice estimate (P2S, 0.4 mm, 0.20 Standard, PLA Basic): 11.7 g, 39 min. Tagged `printable`.

| File | Use |
|---|---|
| `meshes/ax8_threaded_plate.stl` | visual mesh and print geometry (mm, watertight) |
| `print/ax8_threaded_plate.3mf` | native unsliced Bambu Studio project (P2S template) |

Source: `cyberwave-3d/cameras/flir/AX8/v5.0` (STEP and build scripts live there). Not physically printed.
